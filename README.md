# 🌿 PlantCam Promotional Website

![Home Page](https://res.cloudinary.com/dxatb3m2q/image/upload/q_auto,f_auto/v1779330124/Screenshot_2026-05-21_102053_zklxqr.png)

> A modern promotional website showcasing the **PlantCam** application, built using MIT App Inventor with a Webviewer frontend.

PlantCam is a mobile-based application designed for **plant disease diagnosis, detection, and smart recommendation**. It utilizes a robust AI model trained via Google Colab with over 18,000 image datasets specifically for solanaceous plants (potato, tomato, and pepper).

## ✨ Features

- Responsive promotional website
- Home, Privacy, Terms of Service and Disclaimer pages
- APK download link
- AI diagnosis feature explanation
- Figma-based UI implementation

## 💻 Tech Stack

- **Frontend:** HTML, CSS, JavaScript, React, Tailwind CSS, Framer Motion, Lucide React, Vite
- **Design:** Google Stitch, Figma
- **Tools:** Git, MCP

## 🚀 Installation & Setup

1. Open Terminal
2. Clone the repository: `git clone [link]`
3. Change directory to the project: `cd plantcam-promotional`
4. Install dependencies: `npm install`
5. Run the project: `npm run dev`
   > 💡 **Note:** The URL server is `http://localhost:5173`
6. **(Optional)** Building for Production: `npm run build`
